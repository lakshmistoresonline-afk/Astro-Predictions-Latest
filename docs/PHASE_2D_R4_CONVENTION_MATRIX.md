# Phase 2D-R4 Convention Matrix

## 1. Executive Summary
This document specifies the exact astrological conventions, competing traditions, and explicitly selected canonical rules for the Phase 2D-R4 Yoga and Dosha Evaluator.

## 2. Rule Convention Matrix
