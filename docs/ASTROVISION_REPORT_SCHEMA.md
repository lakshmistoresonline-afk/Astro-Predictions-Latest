# Astrovision Report Schema Specification

The canonical report JSON object strictly contains:
- `metadata`: Native details, time, place, coordinates, engine version, ayanamsha.
- `chapter_1_methodology`: Calculation basis.
- `chapter_2_ascendant`: Lagna analysis.
- `chapter_3_planetary_positions`: Grahas data.
- `chapter_3_shadbala`: Quantitative strength.
- `chapter_3_ashtakavarga`: Sarvashtakavarga bindu matrix.
- `chapter_3_jaimini`: Chara karakas.
- `chapter_4_houses`: Bhava analysis.
- `chapter_5_nakshatra`: Lunar mansion profile.
- `chapter_6_divisional_charts`: Vargas D1 to D60.
- `chapter_7_yogas`: Detected yogas & doshas.
- `chapter_8_dasha`: Vimshottari dasha hierarchy.
- `chapter_9_life_domains`: Domain predictions with evidence.
- `chapter_10_transits`: Current planetary transits.
- `chapter_11_remedies`: Traditional upayas.
- `chapter_12_audit_trail`: Calculation hash and disclaimers.
