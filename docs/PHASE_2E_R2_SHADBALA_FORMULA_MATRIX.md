# Phase 2E-R2 Shadbala Formula Matrix

All formulas are evaluated using 64-bit floating point precision from Phase 2A/2B inputs.

```
Total Shadbala (Shashtiamsas) = Sthana + Dig + Kala + Cheshta + Naisargika + Drik

Sthana Bala = Uccha + Sapta Vargaja + Ojha Yugma + Kendradi + Drekkana
Kala Bala = Nathonnatha + Paksha + Ayana + Tribhaga + Vara + Hora + Masa + Varsha

Rupa Conversion = Total Shashtiamsas / 60.0
Strength Percentage = (Total Rupas / BPHS Minimum Required Rupas) * 100.0
```

Where Minimum Required Rupas per BPHS:
- Sun: 5.0 Rupas (300 Shashtiamsas)
- Moon: 6.0 Rupas (360 Shashtiamsas)
- Mars: 5.0 Rupas (300 Shashtiamsas)
- Mercury: 7.0 Rupas (420 Shashtiamsas)
- Jupiter: 6.5 Rupas (390 Shashtiamsas)
- Venus: 5.5 Rupas (330 Shashtiamsas)
- Saturn: 5.0 Rupas (300 Shashtiamsas)
