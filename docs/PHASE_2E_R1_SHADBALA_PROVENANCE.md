# Phase 2E-R1 Shadbala Provenance & Citations

All Shadbala calculations in Phase 2E-R1 strictly trace back to standard classical texts:
- *Brihat Parasara Hora Sastra (BPHS)*, Chapters 27-30 ("Shadbala").
- *Phaladeepika* by Mantreswara, Chapter 4.
