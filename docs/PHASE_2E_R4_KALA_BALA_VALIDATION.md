# Phase 2E-R4 Kala Bala Validation

## Subcomponents Validated
1. **Nathonnatha Bala**: Diurnal/Nocturnal strength based on Sun distance to Nadir (IC).
2. **Paksha Bala**: Sun-Moon phase separation angle (`(angle / 180.0) * 60.0`).
3. **Ayana Bala**: Declination (Kranti) from tropical longitude (`(24 + Kranti) * 1.25`).
4. **Tribhaga Bala**: 1/3rd day/night house partition. (Jupiter = 60.0 always).
5. **Vara Bala**: Day Lord (+45.0 shashtiamsas).
6. **Hora Bala**: Hour Lord (+60.0 shashtiamsas).
7. **Masa Bala**: Month Lord (+30.0 shashtiamsas).
8. **Varsha Bala**: Year Lord (+15.0 shashtiamsas).

All 8 subcomponents verified across 15 fixtures with zero placeholders.
